# LineHX
A pre-configured [Helix](https://github.com/helix-editor/helix) distro for arch linux using plugin enabled [Helix-steel](https://github.com/v1ctorio/helix-steel).
Run by first cloning the [Repo](https://github.com/NikoooGD/LineHX/edit/main/) then run LineHX-arch-linux or Download it from [Releases](https://github.com/NikoooGD/LineHX/releases).
Soon to be available in [Nims](https://nim-lang.org) [package manager](https://www.nimpackages.com/)
